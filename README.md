# 幻想之境 Online

一款向 2000 年代經典寵物 MMORPG 致敬的網頁多人遊戲,玩法以《寵物王 Online》(2003) 為藍本:
**寵物是戰鬥的主角,玩家當訓練師兼輔助。**

完全不需要安裝任何套件:伺服器只用 Python 標準函式庫,畫面由程式即時繪製,
也可以放入 AI 產生的圖片(有圖用圖,沒圖用程式繪圖)。

## 開始遊玩

1. 雙擊 `start.bat`(或在終端機執行 `python server.py`)
2. 瀏覽器會自動打開 http://localhost:8000
3. 輸入角色名稱、選擇職業,進入遊戲!

**和朋友一起玩**:同一個 Wi-Fi / 區網的朋友,用伺服器視窗顯示的「區網朋友」網址連進來即可。
想開多個角色測試,直接多開幾個瀏覽器分頁。

## 遊戲內容

| 系統 | 內容 |
|---|---|
| 戰鬥 | 野外隨機遇敵,戰鬥在原地展開;半即時「時間棒」,時間不會暫停等人 |
| 主人職業 | 騎士(強化寵物)、獵人(捕捉高手)、牧師(治療復活)、法師(操控天氣)、吟遊詩人(歌聲支援) |
| 寵物 | 11 種 × 初階 / 中階 / 高階,加上 2 種混種,共 39 種;六大屬性相剋;力量 / 體質 / 智力 / 敏捷自由配點;技能隨等級學會 |
| 捕捉 | 把野生寵物打到殘血再丟封印卡;天生素質要抓到才知道 |
| 孵蛋 | 向孵化屋婆婆買蛋,調溫度、濕度照顧 60 秒,孵得好就是 12 點極品 |
| 照顧 | 飽食度、快樂值、親密度;每種寵物愛吃的食物不同;肚子餓會變弱、餓昏不肯戰鬥;心情差會不聽指令,太久沒人理還會離家出走 |
| 互動 | 在地圖上點自己的寵物:摸摸、餵食、玩耍、表演(每種寵物有專屬表演);頭上會冒心情泡泡 |
| 親密度 | 主人技能對牠更有效(助攻加成);默契滿了可以「助攻」讓寵物立刻放出強化技;主人血少時寵物會挺身護主 |
| 寵物旅館 | 帶不下的寵物免費寄放在村子東邊的旅館(20 隻),住在旅館不會餓、心情會變好 |
| 配對 | 兩隻 Lv.10 以上、心情好到冒 ♥(發情)的寵物,找孵化屋婆婆配對:小寵種族從爸媽二選一(特殊組合會生出混種)、從爸媽身上挑一個技能遺傳、天生素質至少有爸媽的平均 |
| 進化 | Lv.12 + 親密度 40 → 中階、Lv.24 + 親密度 70 → 高階;能力提升、技能升階,中階學會不能遺傳的專屬技能 |
| 組隊 | 走到別人的戰鬥圈旁點一下就能加入,一場最多 6 人 |
| BOSS | 北方焦土的 Lv.25 炎龍,會噴火,多人挑戰,必掉幼龍蛋 |
| 其他 | 聊天泡泡、密語、小地圖、出戰寵物跟在身邊、自動存檔;下線時寵物狀態暫停 |

## 操作

| 按鍵 | 功能 |
|---|---|
| 滑鼠左鍵 | 移動 / 和 NPC 對話 / 點自己的寵物互動 / 點戰鬥圈加入戰鬥 / 戰鬥中點敵人選目標 |
| WASD、方向鍵 | 移動 |
| P / I / H / M | 寵物 / 背包 / 說明 / 音效 |
| Enter | 聊天(`/w 名稱 訊息` 密語、`/who` 線上名單) |
| 戰鬥:1~6、G | 寵物:1 攻擊、2~6 技能(種族技能、專屬、遺傳)、G 防禦 |
| 戰鬥:Q W E | 主人職業技能 |
| 戰鬥:R / C / X / F | 紅色藥水 / 封印卡 / 換寵 / 逃跑 |
| 戰鬥:T | 助攻(親密度 40 以上、默契滿了) |
| 戰鬥:Tab / 空白鍵 | 切換目標 / 自動戰鬥 |

## 美術圖片

圖片由外部 AI 繪圖工具產生(例如 ChatGPT)。流程見 `docs/art/美術規格.md`,
每隻寵物可以直接複製的 prompt 在 `docs/art/繪圖prompt.md`。

1. 把 prompt 貼到 ChatGPT,下載的原圖用中文名字存到 `art-src/`(例如 `art-src/噗噗.png`)
2. 開伺服器,瀏覽器打開 http://localhost:8000/tools/sprite-tool.html,選那隻寵物(會自動載入原圖),按「存進遊戲」
3. 重新整理遊戲頁面。右下角「美術:圖片 / 程式」可以切換比較

## 檔案結構

```
server.py          伺服器:HTTP + WebSocket + 遊戲邏輯(移動、戰鬥、捕捉、孵蛋、照顧、旅館、NPC、存檔)
game_data.py       遊戲數值:寵物、技能、職業、道具、食物、照顧、遇敵區域、炎龍、圖片大小 ← 調平衡改這裡
public/sprites.js  所有繪圖(地圖、角色、寵物、圖示、心情泡泡)與讀圖系統
public/game.js     客戶端核心(連線、畫面、戰鬥演出、寵物互動動畫、輸入)
public/ui.js       介面視窗(狀態、戰鬥指令、寵物與照顧、旅館、孵蛋器、背包、商店、對話)
public/assets/     遊戲圖片(pets/、npcs/),沒有圖就用程式繪圖
public/tools/      去背 / 裁切小工具
tests/             無頭測試:python tests/test_phase1.py [--balance]、test_phase2.py、test_phase3.py
                   實測用的除錯伺服器:python tests/debug_server.py → http://localhost:8123
                   (另一份存檔 data/debug/,聊天輸入 /gm 可以直接調飽食度、快樂值、親密度、等級、遇敵、離家出走……)
docs/              開發文件:路線圖、各階段 spec / plan / 交接、寵物王研究筆記
data/players.json  角色存檔(第一次有人登入後自動產生,不進 git)
```

開發流程與約定見 `CLAUDE.md`,接下來要做什麼見 `docs/roadmap.md`。
