# 幻想之境 Online

一款向 2000 年代經典寵物 MMORPG 致敬的網頁多人遊戲,玩法以《寵物王 Online》(2003) 為藍本:
**寵物是戰鬥的主角,玩家當訓練師兼輔助。**

完全不需要安裝任何套件:伺服器只用 Python 標準函式庫,畫面全部由程式即時繪製。

## 開始遊玩

1. 雙擊 `start.bat`(或在終端機執行 `python server.py`)
2. 瀏覽器會自動打開 http://localhost:8000
3. 輸入角色名稱、選擇職業,進入遊戲!

**和朋友一起玩**:同一個 Wi-Fi / 區網的朋友,用伺服器視窗顯示的「區網朋友」網址連進來即可。
想開多個角色測試,直接多開幾個瀏覽器分頁。

## 遊戲內容

| 系統 | 內容 |
|---|---|
| 戰鬥 | 野外隨機遇敵,戰鬥在原地展開;半即時「時間棒」,時間不會暫停等人 |
| 主人職業 | 騎士(強化寵物)、獵人(捕捉高手)、牧師(治療復活)、法師(操控天氣)、吟遊詩人(歌聲支援) |
| 寵物 | 11 種、六大屬性相剋;力量 / 體質 / 智力 / 敏捷自由配點;技能隨等級學會 |
| 捕捉 | 把野生寵物打到殘血再丟封印卡;天生素質要抓到才知道 |
| 孵蛋 | 向孵化屋婆婆買蛋,調溫度、濕度照顧 60 秒,孵得好就是 12 點極品 |
| 組隊 | 走到別人的戰鬥圈旁點一下就能加入,一場最多 6 人 |
| BOSS | 北方焦土的 Lv.25 炎龍,會噴火,多人挑戰,必掉幼龍蛋 |
| 其他 | 聊天泡泡、密語、小地圖、出戰寵物跟在身邊、自動存檔 |

## 操作

| 按鍵 | 功能 |
|---|---|
| 滑鼠左鍵 | 移動 / 和 NPC 對話 / 點戰鬥圈加入戰鬥 / 戰鬥中點敵人選目標 |
| WASD、方向鍵 | 移動 |
| P / I / H / M | 寵物 / 背包 / 說明 / 音效 |
| Enter | 聊天(`/w 名稱 訊息` 密語、`/who` 線上名單) |
| 戰鬥:1~5 | 寵物:攻擊、技能 ×3、防禦 |
| 戰鬥:Q W E | 主人職業技能 |
| 戰鬥:R / C / X / F | 紅色藥水 / 封印卡 / 換寵 / 逃跑 |
| 戰鬥:Tab / 空白鍵 | 切換目標 / 自動戰鬥 |

## 檔案結構

```
server.py          伺服器:HTTP + WebSocket + 遊戲邏輯(移動、戰鬥、捕捉、孵蛋、NPC、存檔)
game_data.py       遊戲數值:寵物、技能、職業、道具、遇敵區域、炎龍 ← 調平衡改這裡
public/sprites.js  所有繪圖(地圖、角色、寵物、圖示)
public/game.js     客戶端核心(連線、畫面、戰鬥演出、輸入)
public/ui.js       介面視窗(狀態、戰鬥指令、寵物、孵蛋器、背包、商店、對話)
tests/             無頭測試:python tests/test_phase1.py [--balance]
docs/              開發文件:路線圖、各階段 spec / plan / 交接、寵物王研究筆記
data/players.json  角色存檔(第一次有人登入後自動產生,不進 git)
```
