# 幻想之境 Online

一款向 2000 年代經典 MMORPG(仙境傳說、天堂、石器時代……)致敬的網頁多人線上遊戲。
完全不需要安裝任何套件:伺服器只用 Python 標準函式庫,畫面全部由程式即時繪製。

## 開始遊玩

1. 雙擊 `start.bat`(或在終端機執行 `python server.py`)
2. 瀏覽器會自動打開 http://localhost:8000
3. 輸入角色名稱、選擇職業,進入遊戲!

**和朋友一起玩**:同一個 Wi-Fi / 區網的朋友,用伺服器視窗顯示的「區網朋友」網址連進來即可。
想開多個角色測試,直接多開幾個瀏覽器分頁。

## 遊戲內容

| 系統 | 內容 |
|---|---|
| 職業 | 劍士(近戰、高血量)、法師(遠程魔法)、弓手(射程最遠) |
| 技能 | 每個職業 2 招,第 2 招 Lv.5 解鎖(範圍攻擊) |
| 怪物 | 噗噗 → 綠史萊姆 → 哥布林 → 野狼 → 骷髏兵,越往外越強 |
| BOSS | 北方焦土的 **Lv.25 炎龍**,會噴火,3 分鐘重生,必掉稀有裝備 |
| NPC | 村長、道具商人(買賣)、修女(免費治療)、傳送師(付費傳送) |
| 裝備 | 武器 / 防具各 3~4 階,穿上後角色外觀會改變 |
| 其他 | 死亡懲罰、戰利品優先權、聊天泡泡、密語、小地圖、自動存檔 |

## 操作

| 按鍵 | 功能 |
|---|---|
| 滑鼠左鍵 | 移動 / 攻擊 / 對話 / 撿東西 |
| WASD、方向鍵 | 移動 |
| 空白鍵 | 攻擊最近的怪物 |
| 1、2 | 技能 |
| 3、4 | 紅色 / 藍色藥水 |
| I / H / M | 背包 / 說明 / 音效 |
| Enter | 聊天(`/w 名稱 訊息` 密語、`/who` 線上名單) |

## 檔案結構

```
server.py          伺服器:HTTP + WebSocket + 所有遊戲邏輯(數值、怪物 AI、戰鬥、存檔)
public/index.html  介面骨架
public/style.css   2000 年代風格介面
public/game.js     客戶端:畫面繪製、輸入、特效、音效
data/players.json  角色存檔(第一次有人登入後自動產生)
```

想調整平衡,改 `server.py` 最上面的 `CLASSES`、`SKILLS`、`MOBS`、`ITEMS` 表格,然後重開伺服器即可。

> 伺服器以伺服器端為準(server-authoritative),客戶端只負責送出操作與顯示畫面,所以無法用瀏覽器修改數值作弊。
