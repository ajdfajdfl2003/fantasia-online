# 美術規格

圖由你用 ChatGPT 產生,其他的(去背、裁切、放進遊戲)交給工具。
**要貼的 prompt 全部在 [`繪圖prompt.md`](繪圖prompt.md)**,每一段都是完整的,直接複製就好。

## 你只要做三件事
1. **產圖**:打開 `繪圖prompt.md`,找到那隻寵物,把 prompt 貼到 ChatGPT。
2. **存原圖**:下載後存到專案的 **`art-src/`** 資料夾,**檔名用寵物的中文名字**(見下表)。
3. **存進遊戲**:開伺服器,瀏覽器打開 <http://localhost:8000/tools/sprite-tool.html>,
   選那隻寵物(工具會自動載入 `art-src/` 裡的原圖),看一下預覽,按 **「存進遊戲」**。重新整理遊戲頁面就會看到。

> `public/assets/` 裡的檔案是工具產生的**成品**,不要自己把原圖放進去。

## 原圖的檔名
用寵物的中文名字。主圖一定要有,動作圖可有可無(沒有的話遊戲用程式動畫代替)。

| 種類 | 檔名 | 範例 |
|---|---|---|
| 主圖(必要) | `名字.png` | `art-src/噗噗.png` |
| 攻擊 | `名字_攻擊.png` | `art-src/噗噗_攻擊.png` |
| 受傷 | `名字_受傷.png` | `art-src/噗噗_受傷.png` |
| 睡著 | `名字_睡著.png` | `art-src/噗噗_睡著.png` |

可以用的名字:噗噗、綠史萊姆、哥布林、野狼、骷髏兵、小火妖、彩虹鴿、月狐、吸血蝙蝠、獅鷲獸、幼龍、炎龍。
JPG、WebP 也可以。`art-src/` 不進 git(原圖很大),成品才進 git。

## 一張好圖的條件
- **全身入鏡**,尾巴、耳朵、翅膀都沒被裁掉,四周留一點空白。
- **只有一隻**,沒有文字、浮水印、邊框、散落的道具或特效。
- **透明背景**最好;GPT 做不到時用純白背景(白色系寵物用純綠背景),工具會去背。
- **不要影子、不要地面**(影子由遊戲程式畫)。
- **身體朝右**。畫成朝左也沒關係,工具裡勾「水平翻轉」。
- **粗深色外框把整隻包起來**,去背才不會吃到身體。

## 畫風
**精緻 Q 版**(2026-10-11 試做後定案,不用像素化):粗深棕色外框、平塗加一層陰影、亮面高光、光從左上來、色彩鮮明。
畫風標準圖:`art-src/噗噗.png`、`art-src/小火妖.png`(成品在 `public/assets/pets/`)。
想讓每隻寵物畫風一致:每次開新對話時,先把 `art-src/噗噗.png` 拖進去當參考圖,再貼 prompt。

## 去背工具會幫你做的事(不用管,給程式看的規格)
| 項目 | 規格 |
|---|---|
| 去背 | 從圖片邊緣往內去背(身體裡的白色不會被去掉);原圖已經透明就跳過 |
| 成品 | 256×256 透明 PNG,角色裁到剛好、等比縮放,腳底貼齊底邊正中央,一律朝右 |
| 動作圖的大小 | 依「遊戲裡的主圖」的面積自動對齊(姿勢變寬、變扁,身體還是一樣大);比主圖大時畫布放大,不會把角色縮小。所以**一定要先做主圖**。工具裡有「動作圖大小」可以微調 |
| 像素化(可選) | 畫布邊長 = 顯示大小 ÷ 2,遊戲以 2 倍不平滑放大 |
| 存放位置 | `public/assets/pets/<代號>.png`、`<代號>_attack.png` / `_hurt.png` / `_sleep.png`;NPC 在 `public/assets/npcs/<代號>.png` |

遊戲中的顯示大小(256 圖片像素在畫面上的長度,px),定義在 `game_data.py` 的 `ART`。所有圖用同一個比例,動作圖畫布比較大就畫得比較大。
2026-10-10 實測後整體縮小約 30%,讓寵物跟人物(約 46px 高)比例合理:

| 寵物 | 代號 | 大小 | 寵物 | 代號 | 大小 |
|---|---|---|---|---|---|
| 噗噗 | `poring` | 34 | 彩虹鴿 | `dove` | 44 |
| 綠史萊姆 | `slime` | 36 | 月狐 | `fox` | 60 |
| 小火妖 | `imp` | 40 | 吸血蝙蝠 | `bat` | 44 |
| 哥布林 | `goblin` | 46 | 獅鷲獸 | `griffin` | 78 |
| 野狼 | `wolf` | 60 | 幼龍 | `drake` | 68 |
| 骷髏兵 | `skeleton` | 52 | 炎龍(BOSS) | `dragon` | 160 |

## 其他繪圖工具
prompt 是英文的,其他工具也能用:
- **Midjourney**:加上 `--ar 1:1 --style raw --no shadow, ground, text, scenery`;用 `--sref <噗噗的圖網址>` 讓畫風一致。
- **Stable Diffusion(SDXL)**:1024×1024,負面提示填 `background scenery, ground, cast shadow, text, watermark, multiple characters, cropped, realistic, 3d render`。

## 版權提醒
- 不要拿原作《寵物王》或其他遊戲的圖去改,prompt 裡也不要寫其他遊戲或角色的名字。
- 專案要公開(例如公開的 GitHub repo)之前,先確認繪圖工具的使用條款允許公開使用產出的圖。
