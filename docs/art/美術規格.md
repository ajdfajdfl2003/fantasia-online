# 美術規格

圖由你用 ChatGPT 產生,其他的(去背、裁切、存成 WebP、放進遊戲)交給工具。
**要貼的 prompt 全部在 [`繪圖prompt.md`](繪圖prompt.md)**,每一段都是完整的,直接複製就好。
完整規格與設計理由見 `docs/phase-4/spec.md`(第 1 節圖的清單、第 3 節檔名、第 4 節去背工具、第 5 節美術進度表)。

## 流程:一批一批做
1. **產圖**:打開 `繪圖prompt.md`,照「產圖順序」找到要畫的圖,把 prompt 貼到 ChatGPT。
2. **存原圖**:下載後存到專案的 **`art-src/`** 資料夾,檔名照 prompt 箭頭後面寫的(見下面「原圖的檔名」)。一批畫完再一起處理。
3. **請 Claude 先看一遍**:跟 Claude 說「圖放好了」。Claude 逐張看原圖(spec 第 4.4 節):角色被裁到(尾巴、耳朵、翅膀出框)、
   身體朝左、灰白格子背景、一張圖裡有多隻、有文字或浮水印。有問題會列出檔名和原因,重畫或在工具裡處理(朝左就勾水平翻轉)。
4. **批次存進遊戲**:開伺服器,用 Chrome、Edge 或 Firefox 打開 <http://localhost:8000/tools/sprite-tool.html>,按上方的「批次」。
   工具列出還沒處理的原圖(還沒有成品,或原圖比成品新),一次去背排成縮圖。看過縮圖後按「全部存進遊戲」。
   標紅的會跳過並寫原因;點縮圖進單張模式可以調容許值、筆刷、翻轉,修好按「存進遊戲」。
5. **看進度**:打開 <http://localhost:8000/tools/art-status.html>(美術進度表)。每張圖顯示「已進遊戲」「有原圖還沒處理」「還缺」,
   上方有各類別的完成數,必要的 131 張跟可有可無的分開算。重新整理遊戲頁面就會看到新圖。

> `public/assets/` 裡的檔案是工具產生的**成品**,不要自己把原圖放進去。
> Safari 的 canvas 不能存 WebP:去背工具在 Safari 打開會顯示提示,「存進遊戲」「全部存進遊戲」停用。

批次模式遇到下面這些情況,那張會標紅、寫原因,按「全部存進遊戲」時跳過,其他照存(spec 第 4.3 節):
- 檔名對不上任何一張圖。美術進度表的最下面也會列出來,方便抓打錯的檔名。
- 兩張原圖對到同一張成品(例如 `噗噗.png` 和 `poring.png`):第二張標紅。
- 灰白格子背景(GPT 畫出來的假透明)。
- 動作圖在遊戲裡和同一批裡都沒有這隻的主圖。
- 去背之後什麼都沒剩。
- 存檔時伺服器拒絕:顯示伺服器回的訊息。
- 去背工具還沒支援這類圖(見下表的「去背工具」欄)。

## 一張好圖的條件
- **全身入鏡**,尾巴、耳朵、翅膀都沒被裁掉,四周留一點空白。
- **只有一隻**,沒有文字、浮水印、邊框、散落的道具或特效。NPC 的招牌寵物例外,但要貼在 NPC 身上。
- **透明背景**最好;GPT 做不到時用純白背景,白色系(白袍、白鬍子、白色寵物、白色的蛋)用純綠背景,工具會去背。
  2026-10-14 用假圖實測:米白色、沒有外框的身體會被當成背景去掉。
- **不要影子、不要地面**(影子由遊戲程式畫)。地面材質例外。
- **身體朝右**。畫成朝左也沒關係,工具裡勾「水平翻轉」。
- **粗深色外框把整隻包起來**,去背才不會吃到身體。地面材質例外,不要外框,角色站在上面才顯眼。

## 畫風
**精緻 Q 版**(2026-10-11 試做後定案,不用像素化):粗深棕色外框、平塗加一層陰影、亮面高光、光從左上來、色彩鮮明。
- **寵物**:畫風標準圖是 `art-src/噗噗.png`、`art-src/小火妖.png`(成品在 `public/assets/pets/`)。每次開新對話,先把噗噗拖進去當參考圖。
- **人物**(主人、NPC):2.5 頭身,頭約佔身高 40%。男騎士是人物的畫風標準圖,畫男騎士時上傳噗噗;其他主人上傳男騎士,
  女主人再加上傳同職業的男版圖;NPC 上傳男騎士和招牌寵物的成品圖(spec 第 7、8 節)。
- **女主人**:跟男版同配色、同帽子武器,衣服換女版剪裁(例如騎士穿鎧甲短裙、獵人穿短褲)加長髮。
- **髮色**:每個職業一種、男女同色:騎士栗棕、獵人銅紅、牧師黑、法師銀紫、吟遊詩人金。
- **道具、樹與裝飾**:跟寵物同畫風,上傳噗噗當參考圖。**地面材質**:從正上方看、可以無縫拼接,不要外框。

## 去背工具會幫你做的事(不用管,給程式看的規格)
各類成品(spec 第 4.2 節):

| 類型 | 去背 | 成品 | 對齊 |
|---|---|---|---|
| 寵物、主人、NPC | 要 | 256×256 | 腳底貼齊底邊正中央 |
| 道具 | 要 | 64×64 | 置中,不用腳底對齊 |
| 樹與裝飾 | 要 | 256×256 | 腳底貼齊底邊正中央 |
| 地面材質 | 不要 | 256×256,可無縫拼接 | — |
| 登入主視覺 | 不要 | 1536×1024 | — |
| Logo | 要 | 保留原比例,長邊 1024 | 置中 |

| 項目 | 規格 |
|---|---|
| 格式 | WebP 品質 90,保留透明。2026-10-11 實測 256×256 成品:PNG 約 83~88KB,WebP 品質 90 約 14~21KB;2026-10-13 使用者並排確認畫質 |
| 去背 | 從圖片邊緣往內去背(身體裡的白色不會被去掉);原圖已經透明就跳過 |
| 清掉小碎塊 | 比最大一塊的 2% 還小的區塊清掉。NPC 的寵物、岩石堆、花叢要連成一塊,分開的小塊可能被清掉 |
| 批次模式的設定 | 一律用預設:容許值 40、柔邊 28、清掉小碎塊 2%、上方留白 4、不翻轉、不像素化。要調的點縮圖進單張模式 |
| 動作圖的大小 | 依主圖的面積自動對齊(姿勢變寬、變扁,身體還是一樣大):同一批有主圖就用同一批的,沒有就用遊戲裡的,兩邊都沒有就標紅不存。比主圖大時畫布放大,不會把角色縮小。工具裡有「動作圖大小」可以微調 |
| 地面材質的無縫化 | 原圖縮成 256,位移一半寬高,在接縫處用附近的像素融合;預覽顯示 3×3 拼起來的樣子(plan 第 13 項) |
| 存放位置 | `public/assets/<類別>/<代號>.webp`,動作圖加 `_attack` / `_hurt` / `_sleep` / `_cast`(見上面「原圖的檔名」) |

遊戲中的顯示大小(256 圖片像素在畫面上的長度,px),定義在 `game_data.py` 的 `ART`。所有圖用同一個比例,動作圖畫布比較大就畫得比較大。
2026-10-10 實測後整體縮小約 30%,讓寵物跟人物比例合理:

| 寵物 | 代號 | 大小 | 寵物 | 代號 | 大小 |
|---|---|---|---|---|---|
| 噗噗 | `poring` | 34 | 彩虹鴿 | `dove` | 44 |
| 綠史萊姆 | `slime` | 36 | 月狐 | `fox` | 60 |
| 小火妖 | `imp` | 40 | 吸血蝙蝠 | `bat` | 44 |
| 哥布林 | `goblin` | 46 | 獅鷲獸 | `griffin` | 78 |
| 野狼 | `wolf` | 60 | 幼龍 | `drake` | 68 |
| 骷髏兵 | `skeleton` | 52 | 炎龍(BOSS) | `dragon` | 160 |
| 銀月狼(混種) | `silverwolf` | 60 | 暮光鳥(混種) | `duskbird` | 46 |

進化型態的代號是初階代號加 `2`(中階)、`3`(高階),例如 `poring2`、`poring3`;顯示大小是初階的 1.15 倍、1.3 倍(例如噗噗 34 → 彈彈噗 39 → 噗噗國王 44)。

其他類別:
- **主人** 52(`owner`,男女一樣)。
- **NPC** 每位各自設(`npc_elder` 這種代號),讓人的身高跟主人差不多:村長 68、道具商人 62(寵物在頭頂、背包上,圖比較高),其他 52。
  都是還沒有圖時估的暫定值,圖進來後用比例對照頁調。
- **道具**:背包與戰鬥道具欄顯示 32px,商店與說明視窗放大到 48px。
- **樹與裝飾**:大小之後用比例對照頁定(plan 第 11、21 項)。

## 其他繪圖工具
prompt 是英文的,其他工具也能用:
- **Midjourney**:加上 `--ar 1:1 --style raw --no shadow, ground, text, scenery`;用 `--sref <噗噗的圖網址>` 讓畫風一致。
- **Stable Diffusion(SDXL)**:1024×1024,負面提示填 `background scenery, ground, cast shadow, text, watermark, multiple characters, cropped, realistic, 3d render`。
