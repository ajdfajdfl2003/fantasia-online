# 美術規格與繪圖 prompt 範本

圖由使用者用外部 AI 繪圖工具產生,Claude 負責規格、工具與讀圖系統。
畫風決定見 `../phase-2/spec.md` 第 8 節。

## 流程(從產圖到進遊戲)
1. 從下面複製「共用畫風」+「該寵物的描述」,貼到繪圖工具。一次產 4 張,挑一張最好的。
2. 下載**最大尺寸**的原圖(PNG 最好,JPG 也可以)。原圖可以放在專案的 `art-src/` 資料夾,這個資料夾不進 git。
3. 開伺服器,瀏覽器打開 `http://localhost:8000/tools/sprite-tool.html`。
4. 選要做的寵物 → 把圖拖進去 → 調整去背 → 看預覽 → 按「存進遊戲」。
5. 重新整理遊戲頁面就會看到。不滿意就重做第 4 步,檔案會直接覆蓋。

## 一張好圖的條件
- **全身入鏡**,沒有被裁掉(尾巴、耳朵、翅膀尖都要在畫面內),四周留一點空白。
- **只有一隻**,沒有道具散落、沒有文字、浮水印、邊框。
- **純色背景**:預設純白。身體是白色 / 淡色的寵物(彩虹鴿、月狐、骷髏兵、獅鷲獸)改用**純綠色**背景比較好去背。
- **不要影子、不要地面**(影子由遊戲程式畫)。
- **身體朝右**,側面偏 3/4。畫成朝左也沒關係,工具可以翻轉。
- **輪廓線要封閉**:粗深色外框把整隻包起來,去背才不會「漏」進身體裡。
- 光源固定從**左上方**來,所有寵物才會一致。

## 圖檔規格(工具會自動做好,這裡只是說明)
| 項目 | 規格 |

| 原圖 | 1024×1024 左右,正方形 |

## Prompt 範本
繪圖工具大多用英文效果最好,所以 prompt 用英文,旁邊附中文說明。

### 共用畫風(每次都貼在最前面)
```
cute chibi fantasy creature, 2000s Taiwanese MMORPG pet style, thick dark brown outline,
flat cel shading with one shadow tone, soft highlight, light from upper left, vivid saturated colors,
simple clean shapes, full body, side view facing right, three-quarter view, centered,
single character only, plain solid white background, no shadow, no ground, no text, game sprite asset
```
中文意思:可愛 Q 版奇幻生物、2000 年代台灣網路遊戲寵物風格、粗深棕色外框、平塗加一層陰影、柔和亮點、
光從左上來、鮮豔色彩、造型簡潔、全身、身體朝右的 3/4 側面、置中、只有一隻、純白背景、沒有影子和地面、沒有文字、遊戲素材。

> 白色系的寵物把 `plain solid white background` 換成 `plain solid bright green background`。

### 負面提示(工具有「不要出現」欄位時填這個)
```
background scenery, ground, floor, cast shadow, drop shadow, text, letters, watermark, signature, logo,
border, frame, multiple characters, cropped, cut off, gradient background, realistic, photo, 3d render, blurry
```

### 可選動作圖(同一隻寵物的其他姿勢)
用主圖當參考圖,把描述最後換成:
- 攻擊:`same character, attacking pose, lunging forward, determined expression`
- 受傷:`same character, hurt pose, recoiling backward, eyes squeezed shut`
- 睡著:`same character, sleeping, eyes closed, curled up, peaceful`

AI 很難畫出完全一樣的角色,所以動作圖是**可有可無**的:沒有的話,遊戲用程式動畫(伸縮、前衝、閃白)代替。

## ChatGPT 專用(可以直接複製)
同一個對話裡依序產,後面的寵物才會跟第一張同畫風。

**第 1 張:噗噗**
```
Create a game sprite of a cute chibi fantasy creature for a 2000s Taiwanese MMORPG pet game.
Character: a round pink jelly blob creature, glossy bouncy body, two small black oval eyes, tiny happy smile, a big white shine highlight on top.
Style: thick dark brown outline, flat cel shading with one shadow tone, soft highlight, light from upper left, vivid saturated colors, simple clean shapes.
Pose: full body, side view facing right (three-quarter view), centered, with some empty space around it.
Background: transparent background (PNG). No shadow, no ground, no text, only this one character.
Square image, 1024x1024.
```

**之後每一隻**(把 Character 那行換成上表的英文描述)
```
Great. Now create another creature in exactly the same art style, outline thickness, shading and lighting as the previous image.
Character: a small floating fire imp spirit, round red-orange body, wild hair made of yellow and orange flames, two tiny dark horns, big golden eyes, mischievous grin with a tiny fang, little stubby arms, floating in the air.
Same rules: full body, facing right, centered, transparent background PNG, no shadow, no ground, no text, square 1024x1024.
```

- 不滿意就直接用說的修:「外框再粗一點」「眼睛大一點」「不要那麼寫實」。
- GPT 偶爾會把灰白格子「畫」進圖裡(看起來透明其實不是)。遇到時把背景改成 `plain solid white background`,交給去背工具處理。

## 各家工具的小技巧
| 工具 | 建議 |
|---|---|
| **ChatGPT(圖片生成)** | 可以直接要求「transparent background PNG」(透明背景),工具就不用去背。在同一個對話裡接著說「同樣畫風,改畫 ○○」,畫風最一致 |
| **Midjourney** | 加上 `--ar 1:1 --style raw`,背景與影子寫在 `--no shadow, ground, text, scenery`。畫好第一隻後,用 `--sref <第一張圖的網址>` 讓後面的寵物同畫風;動作圖用角色參考(`--cref` 或 omni reference) |
| **Stable Diffusion(SDXL)** | 解析度設 1024×1024,負面提示貼上面那段。固定 seed 可以讓同一隻寵物的不同姿勢比較像 |
| 其他(Leonardo、Bing 等) | 用同樣的 prompt 即可,記得選正方形 |

### 讓所有寵物畫風一致
1. 先把**噗噗**畫到滿意,當作「畫風標準圖」。
2. 之後每一隻都用同一段共用畫風,並把標準圖當風格參考(Midjourney 的 `--sref`、ChatGPT 同一個對話)。
3. 外框粗細、陰影層數、光源方向不一致時,在 prompt 裡強調那一項重畫。

## 版權提醒
- 不要用原作《寵物王》或其他遊戲的圖去改,也不要在 prompt 裡寫其他遊戲或角色的名字。
