# 階段 3 交接

## 這個階段完成了什麼
寵物可以配對生出下一代、進化成更強的型態,規則可以預測、可以研究:
- **發情與配對**:心情 ♥(快樂值 ≥ 80、親密度 ≥ 60、沒有肚子餓)就是發情。兩隻 Lv.10 以上、發情中的寵物找孵化屋的
  葛莉絲婆婆配對:小寵的種族從爸媽二選一(野狼 × 月狐、彩虹鴿 × 吸血蝙蝠會多一個混種選項)、
  從爸媽的技能挑一個遺傳、天生素質至少有爸媽的平均;付金幣、不會失敗;配完雙親快樂值 −40(自然的冷卻)
- **配對蛋**:婆婆保管(最多 3 顆、會存檔),用孵蛋小遊戲孵;素質 = 下限 + 孵蛋表現;小寵記錄雙親與代數
- **進化**:Lv.12 + 親密 40 → 中階、Lv.24 + 親密 70 → 高階,玩家在寵物視窗「血統」分頁按按鈕;
  能力提升、每級點數 +1 / +2、技能線升階,中階學會不能遺傳的專屬技能;等級不歸零
- **寵物種類**:11 種 × 3 階 + 混種 銀月狼、暮光鳥 × 3 階 = 39 種。進化型態由 `game_data._make_forms()` 從初階產生
- **技能**:18 條技能線的中階 / 高階、13 個專屬技能;戰鬥引擎多了「我方全體」、全體吸血 / 附加狀態、偷金幣
- **介面**:寵物視窗分頁(能力 / 照顧 / 血統)、婆婆的配對視窗(預覽)、孵蛋視窗的配對蛋、戰鬥技能欄 5 格(2~6、防禦改 G)、
  進化光柱;沒有圖的進化型態用初階的圖換顏色、放大,高階身邊有金色光點
- **繪圖 prompt**:`docs/art/繪圖prompt.md` 已經有全部 39 種寵物 + 炎龍的 prompt(進化型態要先上傳初階的圖當參考)
- **測試**:`tests/test_phase3.py` 74 項、階段 2 106 項、階段 1 88 項全過;瀏覽器跑過一輪

詳細規則見 `spec.md`,實作與實測紀錄見 `plan.md`。

## 已知問題與觀察(下一階段可以順便考慮)
- **只有噗噗、小火妖有圖**,其他 37 種是程式繪圖;進化型態沒有圖時借用初階的圖或程式繪圖加 `ctx.filter` 變色。
  `ctx.filter` 在 Chrome / Edge / Firefox 都能用,Safari 舊版不支援(只會放大、不會變色)。換成圖片之後就沒有這個問題。
- **等級內容還不夠**:野外最高到亡者荒原 Lv.13~17、炎龍 Lv.25,高階要 Lv.24,目前要練很久。
  新地圖區域在階段 7(世界擴充),也可以考慮在階段 5 調整經驗值。
- 戰鬥模擬(`python tests/test_phase1.py --balance`)每種情況只跑 60 場,誤差大約 ±6%。要比較改動前後,
  用同一個亂數種子、各跑 200 場比較(這次撕咬就是這樣調的)。
- 戰鬥面板加寬到 740px 才排得下 8 個寵物按鈕;如果之後技能再變多,面板要重新設計。
- 混種只有 2 種,要加新組合改 `game_data.HYBRIDS`、`FORMS`,婆婆的提示在 `BREED_HINTS`。
- 只能跟自己的寵物配對;跟別的玩家配對要有交易 / 同意的介面,留到階段 6。
- 路線圖「待討論」:**伺服器與資料庫**、**上場怪獸的數量**,使用者想找時間討論,開始下一階段前可以先問。

## 開發 / 測試小技巧
- 伺服器:`"%LOCALAPPDATA%\Programs\Python\Python38\python.exe" server.py`。要讓使用者玩的伺服器開在使用者的終端機分頁
  (`run_in_terminal`),`preview_start` 回合結束會被關掉。
- **除錯伺服器** `python tests/debug_server.py` → http://localhost:8123(存檔在 `data/debug/`)。聊天輸入 `/gm` 看指令,
  階段 3 新增:`lv N`(出戰寵物等級)、`q N`(天生素質)、`inh 技能代號`(遺傳技能)、`pet 種族代號 [等級]`(可以直接給進化型態,例如 `pet poring3 26`)。
- Claude 的瀏覽器窗格被隱藏時 `requestAnimationFrame` 會停:用 `setInterval` 自己跑 frame、包住 `handleFx` 記時間、
  `render(t)` 定格、疊一個放大的 canvas 再截圖。輔助函式存在 `localStorage.__helpers`(見階段 2 交接)。
  看一大堆寵物的樣子時,直接在頁面上開一張 canvas 用 `drawCreature` 排成一覽表最快。
- Bash 工具的 heredoc 遇到 JS 的反引號、`\\` 會出錯:要改檔案的腳本一律用 Write 工具寫成 .py 再執行。
- 專案在 OneDrive 裡:`git worktree` 刪不掉 `.git/worktrees/…`(OneDrive 鎖檔),要用 PowerShell 的 `Remove-Item -Recurse -Force`。
  能不用 worktree 就不用。
- 改完伺服器要重開除錯伺服器;只改客戶端重新整理頁面就好。
