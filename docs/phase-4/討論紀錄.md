### 6. 地圖
- **試用 AI 畫地面**:不是一格一格畫,而是 AI 畫「可重複鋪的大張地面材質」(原圖 1024 → 成品 256×256,一張蓋 8×8 格);
  工具做無縫化(位移一半 + 融合接縫);地形交界由程式做柔和過渡;「美術:圖片 / 程式」開關也管地面
- **先試草地一種**,進遊戲看效果;好看再畫其他(森林深色草地、沙路、村莊石板、荒原焦土、水面——水波動畫還是程式畫),不好看就退回程式繪圖
- **樹和裝飾物也換成 AI 圖**,約 9 張:草原樹 2、森林樹 2、荒原枯樹 1、岩石 2、草叢或花叢 2
- 村莊建築留到階段 7 重做大地圖時

### 7. 載入:WebP + 登入時背景預讀
- 實測:256×256 成品 PNG 約 83~88KB;WebP 品質 90(保留透明)14~21KB;無損 WebP 60~73KB。全部約 200 張:PNG 約 17MB、WebP 約 3.5MB
- 去背工具改存 WebP(伺服器的清單、存檔檢查要跟著支援 .webp;現有 8 張 PNG 轉成 WebP)
- 登入畫面一打開就在背景讀主圖;動作圖進遊戲後慢慢讀;還沒讀到的先用程式繪圖,不卡住
- 圖片網址帶版本號,確認伺服器快取設定,第二次進遊戲幾乎不用下載
- 開工後把品質 90 的 WebP 跟 PNG 並排確認畫質
- **注意 Safari**:Safari 的 canvas 不能存 WebP(`toBlob('image/webp')` 會變成 PNG)。去背工具要偵測並提示「請用 Chrome / Edge / Firefox」;
  遊戲本身讀 WebP 沒問題

### 其他:使用者有一台 macOS(2026-10-11 提到)
- 伺服器只用標準函式庫、沒有 Windows 專用的程式,macOS 的 `python3`(3.8 以上)應該可以直接跑:`python3 server.py`。還沒實際在 Mac 上測過
- 字型:CSS 只寫了 Windows 字型(新細明體、標楷體),Mac 會退回蘋方 / 襯線字。這階段改登入畫面時順便加上 Mac 的字型名稱(PingFang TC、BiauKai)
- 專案目前沒有 git remote;搬到 Mac 要複製資料夾或建私人 GitHub repo。`art-src/`、`data/` 不在 git 裡,要另外複製
