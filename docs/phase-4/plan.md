# 階段 4 實作計畫:美術升級(AI 產圖)

規格見 `spec.md`,討論與被否決的方案見 `討論紀錄.md`。分支 `feature/phase-4-art`。
每完成一項就打勾並 commit,推到 origin 的同名分支。

這階段大部分的圖要等使用者產出。所以前半段先做工具和讀圖系統,讓使用者可以一邊產圖;
後半段一批一批把圖放進遊戲、調大小、收尾。每一批圖的流程都一樣:
使用者產圖放進 `art-src/` → Claude 先看原圖(被裁到、朝左、假透明、多隻、有字)→ 批次去背存進遊戲 → 進遊戲確認。

測試在 Mac 用 `python3.8 tests/test_phaseN.py`;merge 回 main 前在 Windows 的 3.8.5 再跑一次。
