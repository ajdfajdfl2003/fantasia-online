# 階段 1 交接

## 這個階段完成了什麼
原型的「玩家即時砍怪」已經整個換成《寵物王》式的寵物戰鬥:
- 野外隨機遇敵,戰鬥在地圖上原地展開;半即時時間棒(不等人,6 秒自動普攻,可開自動戰鬥)
- 主人只能輔助:騎士 / 獵人 / 牧師 / 法師 / 吟遊詩人,各 3 個技能(Lv.1/3/6)
- 11 種寵物、六屬性相剋、天氣、狀態異常;力量 / 體質 / 智力 / 敏捷配點
- 捕捉(封印卡、天生素質隨機)、孵蛋(溫濕度旋鈕小遊戲、12 點極品)、寵物管理(出戰、配點、改名、放生、賣寵)
- 附近玩家點戰鬥圈加入(最多 6 人)、炎龍 BOSS(多人、吐息、暴怒、必掉幼龍蛋)
- 無頭測試 88 項全過;瀏覽器實測過完整流程

詳細規則見 `spec.md`,實作與實測紀錄見 `plan.md`。

## 已知問題與觀察(下一階段可以順便考慮)
- **時間棒對反應慢的人很嚴苛**:掛機或分心時遇敵,寵物只會每 6 秒自動普攻一次,打多隻敵人很容易輸。
  目前是刻意的設計;如果玩家覺得太硬,可以考慮縮短自動普攻時間,或讓遇敵後先有幾秒準備。
- **任何人都能加入別人的戰鬥**:還沒有組隊系統,也沒有「拒絕加入」的開關(階段 5 處理)。
- 主人的經驗值和寵物共用戰鬥經驗,目前主人升級速度和寵物差不多。
- 東西向道路上的橋,木板方向是直的(小問題)。
- 舊版原型的存檔(沒有寵物資料)登入時會自動重新建立角色。

## 開發 / 測試小技巧
- 啟動:`"%LOCALAPPDATA%\Programs\Python\Python38\python.exe" server.py`
- 無頭測試:`python tests/test_phase1.py`,加 `--balance` 跑戰鬥平衡模擬(各區域勝率 / 戰鬥秒數)。
  新階段請新增 `tests/test_phase2.py`,沿用同樣的假時鐘寫法。
- 用 Claude 的內建瀏覽器測試時,如果瀏覽器窗格被隱藏,`requestAnimationFrame` 會停住,畫面不會更新、
  點擊座標也會對不準。可以在頁面上用 JS 手動跑幾個 frame(呼叫 `render()` / `UI.tick()`)再截圖。
- 戰鬥是即時的,AI 透過截圖操作會來不及反應;測試戰鬥時先開自動戰鬥,或用 JS 呼叫 `petCmd()` / `ownerCmd()`。
