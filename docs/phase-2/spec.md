# 階段 2 規格:寵物生活 + 圖片管線

## 目標
讓寵物不只是戰鬥工具,而是要照顧的夥伴:會餓、有心情、跟主人越來越親。親密度回饋到戰鬥(助攻、護主),
心情不好會鬧脾氣。同時把「AI 產圖 → 放進遊戲」的流程打通,試做 噗噗、小火妖 兩隻,定下畫風。

## 已確認的設計決定(2026-10-10 與使用者討論,全部照建議)
| 項目 | 決定 |
|---|---|
| 飢餓的後果 | 不會死。肚子餓 → 能力 −10%、快樂值下降;餓昏 → 不肯出戰 |
| 離線時間 | 下線就暫停,上線接著算;離線超過一天,寵物會撲過來說想你 |
| 食物來源 | 商店(道具商人莉莉)+ 戰鬥掉落;野外採集留到之後的階段 |
| 心情的影響 | 心情差會不聽指令;溫和版離家出走(跑去寵物旅館賭氣,不會消失) |
| 助攻 | 主人技能對自己的寵物效果隨親密度增強 + 新的「助攻」指令(默契量表) |
| 護主 | 連動傷害隨親密度降低 + 主人血少時寵物擋在前面「護主」 |
| 寵物倉庫 | 新 NPC「寵物旅館」、20 隻、免費 |
| 畫風 | 精緻 Q 版(粗輪廓、平塗);工具保留「像素化」,試做時兩種都比較 |
| 試做寵物 | 噗噗 + 小火妖 |
| 動作圖 | 一張主圖 + 程式動畫;可另外放攻擊 / 受傷 / 睡覺圖 |
| 主人、NPC | 這階段不換圖;讀圖系統支援 NPC,主人留到階段 4 |

所有數值都放在 `game_data.py` 的 `CARE`、`FOODS`、`SPECIES`、`ART`,方便調整。

## 1. 照顧數值
每隻寵物多了三個數值,範圍都是 0~100:

| 數值 | 意義 |
|---|---|
| 飽食度 | 吃飽的程度。太低會變弱,0 就餓昏不能戰鬥 |
| 快樂值 | 心情。太低會不聽指令、冒鬧脾氣泡泡,甚至離家出走 |
| 親密度 | 和主人的感情。影響助攻、護主,也讓心情差的寵物比較聽話 |

起始值:

| 來源 | 飽食度 | 快樂值 | 親密度 |
|---|---|---|---|
| 新手送的噗噗 | 80 | 70 | 20 |
| 孵化(原作:買蛋孵的比較忠誠) | 70 | 80 | 30 |
| 捕捉 | 50 | 40 | 0~10 隨機 |
| 階段 1 的舊存檔(補值) | 80 | 70 | 15 |

- **只在線上時變化**:下線就暫停,上線接著算(離線不會餓、不會變心情差)。
- 寄放在寵物旅館的寵物:飽食度、親密度暫停,快樂值慢慢回升。

## 2. 飽食度與餵食

### 消耗(只算線上時間)
| 項目 | 飽食度 |
|---|---|
| 出戰寵物 | 每小時 −15 |
| 身上其他寵物 | 每小時 −7.5 |
| 每場戰鬥(有上場過的寵物) | −0.5 |
| 玩耍 | −5 |

一直練功大約一小時要餵一次(一小時約 100 場戰鬥)。

### 狀態
| 飽食度 | 狀態 | 效果 |
|---|---|---|
| 30 以上 | 正常 | — |
| 1~29 | 肚子餓 | 戰鬥時攻擊、魔攻、防禦、魔防 ×0.9;快樂值每小時額外 −60;冒 🍖 泡泡 |
| 0 | 餓昏 | 不肯出戰(遇敵、換寵、加入戰鬥都不會派牠);快樂值每小時額外 −120;歸零那一刻親密度 −2 |

- 全部寵物都餓昏(或倒下)時不會遇敵,可以安全走回村莊。
- 戰鬥中飽食度掉到 0 不會被趕下場,下一場才不能出戰。

| 麥穗 | 5 | 彩虹鴿、哥布林 |
| 木材 | 5 | 骷髏兵(原作「排骨吃木材」) |

**戰鬥掉落**:打倒野生寵物時有 25% 機率掉出牠最愛的食物(綠史萊姆掉隨機一種)。

|---|---|---|---|---|
| 最愛 | +35 | +10 | +4 | 「好好吃!」♥ |

## 3. 快樂值與心情

### 變化
| 事件 | 快樂值 |
|---|---|
| 自然下降(無聊) | 每小時 −6(身上的寵物) |
| 肚子餓 / 餓昏 | 每小時額外 −60 / −120 |
| 餵食 | 見口味表 |
| 摸摸 / 玩耍 / 表演 | +5 / +15 / +3 |
| 打贏(有上場、沒倒下) | +1 |
| 升級 | +10 |
| 倒下 | −5 |
| 打輸(有上場的寵物) | −10 |
| 寄放在旅館 | 每小時 +60 |

### 心情泡泡
寵物頭上會冒泡泡。同時符合多個時,依下表由上往下取第一個:

| 泡泡 | 條件 | 出現在 |
|---|---|---|
| 🍖✕ 餓昏 | 飽食度 0 | 地圖、戰鬥 |
| 🍖 肚子餓 | 飽食度 < 30 | 地圖、戰鬥 |
| 💢 鬧脾氣 | 快樂值 < 30 | 地圖、戰鬥 |
| 💦 害怕發抖 | HP < 30%,或敵人等級 ≥ 自己 +5(身體也會發抖) | 戰鬥 |
| Zzz 打瞌睡 | 主人 20 秒沒動 | 地圖 |
| ♥ 春心蕩漾 | 快樂值 ≥ 80 且親密度 ≥ 60(階段 3 接到發情) | 地圖 |
| ♪ 開心 | 剛被餵最愛 / 喜歡的食物、摸摸、玩耍(短暫) | 地圖 |

地圖上的泡泡每 8 秒冒 3 秒(Zzz 一直冒),別的玩家也看得到。

### 不聽指令
- 快樂值 < 30:15% 機率不聽;< 10:30% 機率不聽。
- 親密度會降低機率:實際機率 × (1 − 親密度 ÷ 200),親密度 100 時減半。
- 不聽的時候,一半機率「哼!」發呆(這回合浪費掉),一半機率自己亂打一隻敵人。
- 會檢查的時機:玩家下的寵物指令、自動戰鬥。不檢查:6 秒沒下指令的自動普攻(那本來就是寵物自己的決定)。
- 「助攻」發動後的那一招一定聽話。

### 離家出走(溫和版)
- 快樂值和飽食度**都是 0**,在戰鬥外持續 10 分鐘(只算線上時間)→ 寵物跑去寵物旅館賭氣。
- 持續 5 分鐘時先警告:「○○ 好像快受不了了……」。
- 出走時:親密度 −10;旅館老闆娘會餵牠一點東西(飽食度變成 30);旅館滿了也收(賭氣的不佔格子)。
- 在旅館標示「賭氣中」,到旅館免費帶回來。寄放期間快樂值會慢慢回升。
- 身上最後一隻寵物也可能出走。身上沒有寵物時不會遇敵,走回村莊找旅館就好。

## 4. 親密度

### 變化
| 事件 | 親密度 |
|---|---|
| 餵最愛 / 喜歡的食物 | +4 / +2 |
| 摸摸(冷卻 3 分鐘) | +0.5 |
| 玩耍(冷卻 10 分鐘) | +1 |
| 打贏(有上場、沒倒下) | +0.05 |
| 倒下 | −1 |
| 餓昏(歸零那一刻) | −2 |
| 離家出走 | −10 |

### 助攻 A:職業技能加成
主人的技能用在**自己的寵物**身上時,效果 × (1 + 0.5 × 親密度 ÷ 100),親密度 100 時 ×1.5。

| 技能類型 | 加成的部分 | 例子(親密度 100) |
|---|---|---|
| 強化狀態(鼓舞、守護、魔力增幅、戰歌) | 增加的幅度 | 鼓舞 攻擊 +30% → +45% |
| 治癒術、防護罩、復活術 | 回復量 / 護罩量 / 復活血量 | 治癒術 35% → 52.5% |
| 疾風 | 時間棒增加量 | +50 → +75 |
| 魔力之歌 | 回復的 MP | |

用在別的玩家的寵物、或對敵人的技能(威嚇、遲緩、安眠曲、天氣)沒有加成。發動時會冒「助攻 +X%」。

### 助攻 B:默契量表 + 「助攻」指令
- 親密度 **40** 以上解鎖。戰鬥指令面板的寵物列多一個「助攻」按鈕(快捷鍵 **T**),旁邊顯示默契量表。
- 累積:寵物每次行動 +6、每次被打 +4,再 × (0.5 + 親密度 ÷ 100)。量表**跨戰鬥保留**(會存檔)。
- 量表滿 100 時主人可以發動,**不用等主人的時間棒**:
  - 寵物的時間棒立刻集滿;
  - 下一招(攻擊或技能)威力 ×1.5(治療量 ×1.5、狀態技成功率 ×1.5)、**不耗 MP**、一定聽話。
- 畫面:寵物發光、「心意相通!」。自動戰鬥不會自己發動助攻。
- 大概的頻率:親密度 40 約 3 場一次,親密度 100 約 2 場一次。

### 護主 A:連動傷害減少
寵物受傷連動到主人的比例 = 15% − 10% × 親密度 ÷ 100(親密度 100 時只剩 5%)。

### 護主 B:護主姿態
- 條件:親密度 ≥ **60**,主人 HP 掉到 30% 以下,寵物還在場上。
- 寵物退到主人身前「挺身護主!」:連動傷害變 0、寵物防禦和魔防 ×1.3,狀態欄顯示「護主」。
- 主人 HP 回到 50% 以上、或寵物倒下時結束。

## 5. 互動動作
在地圖上點**自己的寵物**(跟在身邊那隻)跳出選單;寵物視窗也有同樣的按鈕(可以對身上任何一隻)。

| 動作 | 效果 | 冷卻 | 條件 |
|---|---|---|---|
| 摸摸 | 快樂 +5、親密 +0.5,寵物蹦一下冒愛心 | 3 分鐘 | — |
| 餵食 | 見口味表(選單列出背包裡的食物,並標示最愛 / 討厭) | — | 飽食度 < 90 |
| 玩耍 | 快樂 +15、親密 +1、飽食 −5,寵物繞著主人跑跳 | 10 分鐘 | 飽食度 ≥ 10 |
| 表演 | 快樂 +3,做出種族專屬的動作,附近玩家看得到 | 30 秒 | 親密度 ≥ 50 |

冷卻中再點,寵物還是有反應,但數值不會變。只能在戰鬥外互動。

| 噗噗 | 彈跳三連 | bounce |
| 綠史萊姆 | 軟Q壓扁 | squash |
| 哥布林 | 揮棒轉圈 | spin |
| 野狼 | 仰天長嚎「嗷嗚~」 | howl |
| 骷髏兵 | 骨頭喀啦喀啦 | shake |
| 小火妖 | 噴火圈 | fire |
| 彩虹鴿 | 繞圈飛 | circle |
| 月狐 | 追自己的尾巴 | spin |
| 吸血蝙蝠 | 倒吊 | flip |
| 獅鷲獸 | 展翅高飛 | jump |
| 幼龍 | 噴出小火苗 | fire |

動作做成通用的變形(彈跳、壓扁、轉圈、跳、抖、翻、繞圈、火焰粒子),程式繪圖和圖片都能用。

## 6. 寵物旅館
- 新 NPC **寵物旅館 蘿絲**,在村子東側(孵化屋葛莉絲婆婆的對面)。
- 可以寄放 **20** 隻,**免費**。身上至少要留一隻。
- 寄放時 HP、MP 補滿;寄放期間飽食度、親密度暫停,快樂值每小時 +60(在旅館玩耍)。心情差的寵物可以送來休息。
- 對話選項「寄放 / 領回寵物」開啟旅館視窗:左邊身上的寵物、右邊旅館裡的寵物,各有「寄放 →」「← 領回」。
- 身上滿 5 隻時,捕捉、孵蛋的提示會改成「可以寄放到寵物旅館」。
- 存檔欄位 `bank`。

## 7. 離線與回歸
- 離線時所有數值暫停。
- 離線超過 24 小時再上線:出戰寵物撲過來冒 ♥「想你了!」(只是演出,數值不變)。

## 8. 圖片管線

### 畫風
**精緻 Q 版**:粗深色輪廓、平塗加簡單陰影、色彩鮮明,接近原作的感覺。粗輪廓也讓去背比較乾淨。
工具保留「像素化」(縮小 + 減色 + 描邊),試做時兩種都放進遊戲比較再定案。

### 圖檔規格
| 項目 | 規格 |
|---|---|
| 原圖(使用者用 AI 產生) | 1024×1024 左右,單隻、全身、身體朝右(側面偏 3/4)、純白或純色背景,不要影子、地面、文字。能直接輸出透明 PNG 更好 |
| 成品(工具產生) | 256×256 透明 PNG;角色裁到剛好,等比縮放塞進畫布,**腳底貼齊底邊正中央**;一律朝右 |
| 像素化成品 | 畫布邊長 = 顯示大小 ÷ 2,遊戲用 2 倍不平滑放大 |
| 檔名 | `public/assets/pets/<種族>.png`,例如 `poring.png`、`imp.png` |
| 可選動作圖 | `<種族>_attack.png`(攻擊)、`_hurt.png`(受傷)、`_sleep.png`(睡著 / 打瞌睡),規格同主圖 |
| NPC(之後用) | `public/assets/npcs/<NPC 類別>.png`,例如 `hatcher.png`,站著不動、朝右 |

**顯示大小**(`game_data.py` 的 `ART`,單位 px,是 256 畫布在遊戲裡的邊長,比現在的程式繪圖大約 1.5 倍):

| 寵物 | 大小 | 寵物 | 大小 | 寵物 | 大小 |
|---|---|---|---|---|---|
| 噗噗 | 48 | 野狼 | 86 | 吸血蝙蝠 | 60 |
| 綠史萊姆 | 52 | 骷髏兵 | 72 | 獅鷲獸 | 110 |
| 小火妖 | 56 | 彩虹鴿 | 60 | 幼龍 | 96 |
| 哥布林 | 66 | 月狐 | 86 | 炎龍(BOSS) | 220 |

會飛的寵物(小火妖、彩虹鴿、吸血蝙蝠)另外有「浮空高度」,圖片會飄在影子上方。

### 讀圖系統
- 伺服器提供 `/assets.json`:列出 `public/assets/` 裡有哪些圖,以及每種寵物的顯示大小。客戶端進遊戲時讀取。
- **有圖用圖,沒圖退回程式繪圖**;圖片讀取失敗也退回程式繪圖。
- 程式動畫套用在圖片上:呼吸(微微伸縮)、走路彈跳、浮空擺動、攻擊前傾、受傷閃白、倒下變灰、朝左時水平翻轉、
  影子依圖片寬度畫在腳下。有放可選動作圖時,攻擊 / 受傷 / 睡著的那一刻換圖。
- 名字和血條的高度依圖片實際內容自動計算。
- 選單有「美術:圖片 / 程式」開關,方便比較。

### 去背 / 裁切小工具(`public/tools/sprite-tool.html`)
在瀏覽器打開 `http://localhost:8000/tools/sprite-tool.html`,零安裝:
1. 選目標(寵物種族 + 主圖或動作圖,或 NPC),顯示要的檔名與遊戲中大小。
2. 放入圖片:拖曳、選檔、或 Ctrl+V 貼上。
3. 去背:從邊緣往內「漫水」去背(可調容許值),可選「也去掉被圍住的背景」(色鍵);邊緣半透明處去掉背景色;
   「只保留最大的一塊」清掉雜點;已經是透明圖就跳過。另有橡皮擦 / 還原筆刷手動修。
4. 自動裁切、置中、腳底對齊;可以水平翻轉(原圖朝左時)。
5. 像素化(可選):縮到顯示大小 ÷ 2、限制顏色數、加深色外框。
6. 預覽:草地和戰鬥圈背景、遊戲中實際大小、呼吸動畫,旁邊並排程式繪圖的版本。
7. 輸出:「下載 PNG」或「存進遊戲」(直接寫進 `public/assets/`,只接受本機連線、只接受規定的檔名)。

### 繪圖 prompt 範本
寫在 `docs/art/美術規格.md`:共用的畫風關鍵字、每種寵物的外觀描述、負面提示、
各家工具(Midjourney、ChatGPT / DALL·E、Stable Diffusion)的注意事項、讓多張圖畫風一致的方法、從產圖到進遊戲的步驟。

### 試做
噗噗、小火妖:使用者依範本產圖 → 工具去背裁切 → 放進遊戲 → Q 版和像素化各看一次 → 定案畫風,寫回本文件。
