# 階段 2 交接

## 這個階段完成了什麼
寵物從「戰鬥工具」變成要照顧的夥伴,並打通了「AI 產圖 → 放進遊戲」的流程:
- **照顧**:飽食度、快樂值、親密度(只在線上時變化,下線暫停);6 種食物,每個種族有最愛 / 討厭的口味;
  肚子餓能力 −10%、餓昏不肯出戰;離線超過一天,寵物撲過來說想你
- **互動**:在地圖上點自己的寵物 → 摸摸、餵食、玩耍(繞主人一圈)、表演(11 種寵物各有專屬表演);
  頭上冒心情泡泡(餓昏、肚子餓、鬧脾氣、害怕發抖、打瞌睡、春心蕩漾、開心),別的玩家也看得到
- **心情**:快樂值低會不聽指令(發呆或亂打);快樂值和飽食度都是 0 太久會離家出走(溫和版:跑去旅館賭氣)
- **親密度**:主人技能對自己的寵物更有效(助攻 A);默契量表滿了按「助攻」(T),寵物立刻行動、威力 ×1.5(助攻 B);
  連動傷害隨親密度降低(護主 A);主人血少時寵物挺身護主(護主 B)
- **寵物旅館**:村子東側的蘿絲,免費寄放 20 隻,住在旅館心情會變好
- **圖片管線**:讀圖系統(有圖用圖、沒圖用程式繪圖、程式動畫套在圖上、可選攻擊 / 受傷 / 睡著圖)、
  去背小工具 `public/tools/sprite-tool.html`、prompt 產生器 `docs/art/gen_prompts.py`;
  畫風定案**精緻 Q 版**,噗噗、小火妖各 4 張圖已進遊戲
- **測試**:`tests/test_phase2.py` 106 項、`tests/test_phase1.py` 88 項全過;
  新增除錯伺服器 `tests/debug_server.py`,瀏覽器裡逐格看過全部動畫與演出(含 11 種表演)

詳細規則見 `spec.md`,實作與兩輪實測修掉的問題見 `plan.md`。

## 開發 / 測試小技巧
- 伺服器:`"%LOCALAPPDATA%\Programs\Python\Python38\python.exe" server.py`。
  要讓使用者玩的伺服器開在使用者的終端機分頁(`run_in_terminal`),不要用 `preview_start`(回合結束會被關掉);
  重開前先看終端機有沒有人在線上。
- **除錯伺服器** `python tests/debug_server.py` → http://localhost:8123,存檔在 `data/debug/`(不動正式存檔)。
  聊天輸入 `/gm` 看指令:`food / joy / bond / sync 數值`、`php N`、`hp N`、`enc [+N]`(立刻遇敵,敵人等級 +N)、
  `sulk [秒]`、`miss`、`away`、`pet 種族 [等級]`、`give 道具 [數量]`、`gold N`。階段 3 可以加 `/gm` 指令(例如直接發情、加進化值)。
  `.claude/launch.json` 的 `fantasia-debug` 就是它,可以用 `preview_start` 給 Claude 自己測。
- **Claude 的瀏覽器窗格被隱藏時**:`requestAnimationFrame` 會停。做法(這次實測用的):
  1. 用 `setInterval` 自己跑 frame(照 `frame()` 的內容呼叫 `updateFollowers` / `render` / `UI.tick`);
  2. 包住 `handleFx` 記下特效的時間 `t`,再用 `render(t + 毫秒)` 定格在動畫的任何一刻(要依時間由早到晚畫,粒子會被過濾掉);
  3. 截圖的座標是 800×450,畫布是 1280×720,`zoom` 不會放大 → 在頁面上疊一個 canvas,
     把要看的區域用 `imageSmoothingEnabled = false` 放大 3~4 倍畫上去,再截圖;
  4. 這些輔助函式存在 `localStorage`,重新整理後 `(0, eval)(localStorage.__helpers)` 就能再用。
- 測試用另一份存檔:環境變數 `FANTASIA_DATA=<資料夾>`。
- Bash 工具的 heredoc 會把 `\\` 吃成 `\`:含反斜線的腳本用 Write 工具寫成檔案再執行。
- JS 的選項預設值:`o.gap || 120` 會把 `0` 當成沒給(這次噴火圈就是這樣壞的),數字選項用 `??`。
- 圖片:原圖放 `art-src/`(中文檔名,不進 git),工具存進 `public/assets/`;改 prompt 改 `docs/art/gen_prompts.py` 再執行。
