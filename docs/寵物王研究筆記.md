# 寵物王 Online(Petrealm)研究筆記

> 整理日期:2026-10-10。資料來自 2003 年中華網攻略存檔(web.archive.org)、巴哈姆特、百度百科、PTT。
> 標「待證實」的是玩家回憶或單一來源。

## 基本資料
- 第三波開發,台灣由宏碁戲谷代理,2003 年上市;停運:大陸 2004.3、香港 2004.10、台灣 2004.12
- 2D 場景 + 3D 寵物模型,Q 版風格
- 世界:三國(范塔西雅王國 / 亞美辛尼亞共和國 / 汪德蘭聯邦)爭奪「龍島」,用「魔寵競技」代替戰爭;有國戰

## 戰鬥
- **野外隨機遇敵**,切到獨立戰鬥畫面(類似石器時代)。職業影響遇敵率(法師最高、獵人最低)
- **半即時「時間棒」**(類似 ATB):寵物與主人各有時間棒,集滿就行動,敏捷/速度快的先動
- 隊伍最多 6 人,每人一隻寵物上場,可中途換寵
- **人物不能直接攻擊**,只能輔助(這點和石器、魔力最大的不同)
- 寵物受傷 → 主人也間接扣 HP;忠心(親密度高)的寵物會保護主人
- 「助攻」:場外也能幫寵物發動強化技;親密度越高,助攻效果越強(親密度 22 ≈ 法力增強 Lv2)
- 技能熟練度不夠會 FAIL(施放失敗)

## 人物職業(5 種,無種族,只有性別與國籍)
| 職業 | 戰鬥中的作用 |
|---|---|
| 騎士 | 我方寵物攻防 ↑、敵方寵物攻防 ↓ |
| 獵人 | 縮短我方時間棒、拉長敵方時間棒、降敵閃避;隱性:捕捉成功率高 |
| 牧師 | 大量補寵物血、防護罩(神蹟之光) |
| 法師 | 寵物魔攻/魔防 ↑,可改變戰場**天氣、日夜、地形** |
| 吟遊詩人 | 心靈系防護與攻擊(魔力之歌);隱性:時間棒較快 |

職業技能從 6 選 3,但其中 2 個是共通技(補血、護罩),導致同職業幾乎一樣(內測心得批評)。

## 寵物
- 200+ 種,六屬性:地、水、風、火、光、暗
- 科別:野獸、蟲獸、翼獸、類人、妖精、巨人
- 身上最多 5 隻(封印卡)
- 能力值:力量 / 體質 / 智力 / 敏捷
  - 1 體質 = +4 HP;1 智力 = +3 MP、約 +0.8 魔攻;力量影響物攻;敏捷影響速度與 MP 回復
  - 每升一級得到 3~5 點自由分配(依種族不同),極品寵(火妖、影子)+6
- 寵物有初階 → 中階 → 高階,技能也隨之升階

## 取得寵物
1. **買蛋孵化**:每種寵物有最佳溫度/濕度,孵得準 →「12 點」極品寵。商店蛋孵出的先天體質較好、忠誠度較高。
   但大多數孵出來是「垃圾寵」(可賣約 1000)
   | 寵物 | 溫度 | 濕度 |
   |---|---|---|
   | 小火妖 | 90 | 10 |
   | 樹精寶寶 | 90 | 90 |
   | 翼精 | 40 | 80 |
   | 骷髏人 | 80 | 30 |
   | 獅鷲獸 | 60 | 60 |
   | 波力馬 | 50 | 50 |
2. **戰鬥中捕捉**(獵人成功率較高)— 但捕捉的寵物點數平均分配,沒有戰鬥培養價值(內測心得批評)
3. **交配**:需等寵物「發情」;小寵隨機是父或母的種族,3 個技能從雙親共 6 個中隨機抽;會「交配失敗」
4. **進化**:依進化值,由玩家決定何時進化

## 照顧(電子雞元素)
- 體力(飽食)與快樂值;各種族愛吃的食物不同(火妖吃礦石、排骨吃木材)
- 心情泡泡:鬧脾氣、害怕發抖、打瞌睡、春心蕩漾
- 清便便、玩具、互動動作
- 親密度:餵最愛的食物最快,陪玩較慢
- 會餓死 → 2003.3 加入「寵物銀行」寄放
- 心情不好不上班、離家出走(PTT 玩家回憶,待證實)

## 經濟
- 打怪幾乎不掉錢;主要靠**寵物打工**:在訓練所學「技工」等技能 → 去工廠打工;會疲勞要睡覺,要餵食
- 好的中階打工寵一次賺幾千
- 訓練所:花錢 + 時間掛技能熟練度(玩家抱怨太慢,要開機掛一整晚)

## 當年玩家的批評(值得避開)
1. 寵物平衡差 → 戰場只剩翼精、食屍鬼、骷髏人等十幾種
2. 交配讓好技能集中到高成長寵 →「天下武學殊途同歸」,每隻都一樣
3. 捕捉的寵物沒有價值(點數平均)
4. 職業技能雷同,人物缺乏個性
5. 任務獎勵爛、賠本
6. 掛技能、掛發情要整晚開機,純耗時間
7. 國戰只是一堆 1v1 / 6v6 累加,沒有大規模團戰感
