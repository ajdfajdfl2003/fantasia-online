# 開發路線圖

方向:以《寵物王 Online》為藍本的寵物養成 MMORPG。寵物是戰鬥主角,玩家當訓練師兼輔助。
同時修正原作被玩家批評的缺點(見 `寵物王研究筆記.md` 最後一節)。

| 階段 | 名稱 | 狀態 |
|---|---|---|
| 0 | 原型 | ✅ 完成 |
| 1 | 寵物戰鬥核心 | ✅ 完成 |
| 2 | 寵物生活 + 圖片管線 | ✅ 完成 |
| 3 | 繁殖與進化 | ✅ 完成 |
| 4 | 美術升級(AI 產圖) | 待開始 |
| 5 | 經濟與成長 | 待開始 |

| 7 | 世界擴充 | 待開始 |

### 美術方向(2026-10-10 決定)
- 圖由使用者用外部 AI 繪圖工具(Midjourney、DALL·E、Stable Diffusion 等)產生;Claude 無法直接產圖,
  負責:訂圖檔規格、寫繪圖 prompt 範本、做讀圖與動畫系統、整理圖片(去背、裁切、縮放)。
- 圖片可以一張一張慢慢換:有圖就用圖,沒圖就退回目前的程式繪圖。
- AI 很難畫出動作連貫的動畫格,所以預設每隻寵物「一張主圖」,呼吸、彈跳、衝刺、受傷閃爍由程式做。
- 正式全面產圖放在繁殖與進化之後,等寵物種類與進化型態定案,避免畫完又改。

## 階段 0:原型 ✅
可以玩的地基:網路連線、地圖與村莊、NPC 對話、商店、聊天、存檔、像素畫面。
原本的即時砍怪戰鬥與劍士/法師/弓手,會在階段 1 被取代。

## 階段 1:寵物戰鬥核心 ✅
規格見 `phase-1/spec.md`,實作紀錄見 `phase-1/plan.md`。
- 隨機遇敵,戰鬥在原地展開(不切換畫面)
- 半即時「時間棒」戰鬥:時間不等人,選太久寵物自動普攻,可開自動戰鬥
- 主人不能攻擊,只能輔助:騎士、獵人、牧師、法師、吟遊詩人 5 職業
- 寵物四項能力(力量/體質/智力/敏捷)、升級自由配點、技能隨等級學會
- 捕捉:封印卡,野生寵物天生素質隨機(修正原作「抓到的寵物沒用」)
- 孵蛋:溫度/濕度旋鈕小遊戲,孵得好就是「12 點寵」
- 寵物管理介面、其他玩家可以加入正在進行的戰鬥、炎龍 BOSS 改成寵物戰

## 階段 2:寵物生活 + 圖片管線 ✅
規格見 `phase-2/spec.md`,實作與實測紀錄見 `phase-2/plan.md`,交接見 `phase-2/handoff.md`。

寵物生活:
- 飽食度與餵食:每個種族愛吃的食物不同(礦石、木材、肉……)
- 快樂值與心情泡泡(鬧脾氣、害怕發抖、打瞌睡、春心蕩漾)
- 親密度:影響「助攻」強度,親密度高的寵物會保護主人
- 寵物互動動作、寵物跟在主人身邊的表情
- 寵物倉庫(銀行):身上 5 隻以外的寵物寄放在村裡

圖片管線(先把基礎打好,讓使用者可以開始試畫風):
- 決定畫風(像素風,或接近原作的精緻 Q 版)與圖檔規格(尺寸、透明背景、朝向、腳底對齊點)
  → **2026-10-11 定案:精緻 Q 版**(試做噗噗、小火妖後決定)
- 讀圖系統:`public/assets/` 裡有圖就用圖,沒有就退回程式繪圖;程式動畫套用在圖片上
- 統一的繪圖 prompt 範本(同畫風、同光源、純色背景方便去背)
- 去背 / 裁切 / 縮放小工具(零安裝:做成瀏覽器裡的工具頁面)
- 試做 1~2 隻寵物,確認畫風與流程

## 階段 3:繁殖與進化 ✅
規格見 `phase-3/spec.md`,實作與實測紀錄見 `phase-3/plan.md`,交接見 `phase-3/handoff.md`。
- 配對(孵化屋婆婆兼辦):發情 = 心情 ♥;小寵種族二選一、遺傳技能自己挑、天生素質有下限,規則可預測、不會失敗
- 進化:初階 → 中階 → 高階,技能跟著升階;中階學會不能遺傳的專屬技能
- 寵物從 11 種變成 39 種(11 種 × 3 階 + 混種 銀月狼、暮光鳥 × 3 階);新的基本種族留到階段 7

## 階段 4:美術升級(AI 產圖)
- 依階段 2 定下的規格與 prompt 範本,產出全部寵物(39 種,含進化型態與混種;prompt 已經在 `art/繪圖prompt.md`)、5 職業主人、NPC、炎龍
- 道具與技能圖示、登入畫面主視覺與 Logo
- 地圖圖塊視情況:AI 很難畫出能無縫拼接的圖塊,可能維持程式繪圖或另外處理
- 依實際效果調整:圖片大小、站位、血條與名字的位置、戰鬥特效的比例

## 階段 5:經濟與成長
- 寵物打工:學技能、去工廠工作賺錢,會疲勞要休息
- 訓練所:提升技能熟練度。花錢可以加速,不需要整晚掛機
- 玩家之間的交易

## 階段 6:社交與對戰
- 組隊系統(隊伍、經驗分配、隊長)
- 魔寵競技:玩家寵物對戰 PvP
- 公會
- 國戰:三國,參考原作內測心得建議的「搶旗模式」大規模戰場

## 階段 7:世界擴充
- 三國大地圖:范塔西雅王國、亞美辛尼亞共和國、汪德蘭聯邦,中間的龍島
- 迷宮、任務線、更多 BOSS
- 背景音樂

## 待討論(使用者 2026-10-11 提出,之後找時間一起討論)
- **伺服器與資料庫**:現在是單一 Python 3.8 程序(標準函式庫 asyncio,邏輯 20 Hz),
  存檔是一個 JSON 檔 `data/players.json`,每 30 秒和登出時整份寫入。
  要討論:玩家變多時的架構、要不要換成資料庫(例如標準函式庫就有的 SQLite)、備份、架到網路上給別人玩。
- **上場怪獸的數量**:現在每位玩家戰鬥中只有 1 隻寵物上場(加上主人),野外遇敵 1~4 隻
  (草原 1~2、森林與山丘 1~3、荒原 1~4),一場戰鬥最多 6 位玩家加入。
  要討論:一次可以派幾隻寵物上場、敵人要幾隻。

## 優化清單(之後再做)
玩的時候想到的小改善,不屬於目前階段,先記在這裡,之後挑時間一起做。
- **區域提示**(2026-10-10):小地圖標題顯示目前區域與等級範圍(例如「迷霧森林 Lv.4~8」);
  走進新區域時畫面中間短暫跳出區域名稱;小地圖淡淡畫出各區分界。目前畫面沒有顯示自己在哪一區。
- **登入與註冊分開**(2026-10-11):現在登入畫面只有一個「進入遊戲」,名字不存在就直接建立新角色,
  登入和註冊混在一起(打錯名字會不小心多開一個角色)。改成「登入」和「建立角色」兩個分頁 / 按鈕,
  建立角色時才選職業、輸入兩次密碼;登入時名字不存在要提示。
- **離開 NPC 時對話自動關閉**(2026-10-11):走離 NPC 一定距離後(或離開城裡、離 NPC 夠遠),跟那位 NPC 的對話視窗自動消失。
  目前對話框會一直開著,走遠了再按選項只會跳「距離太遠了」(伺服器規定 4 格內才能操作)。商店、孵蛋器、寵物旅館、配對這些 NPC 視窗可以一併考慮。
