# 遊戲圖片(成品)

這裡的圖是**去背工具產生的成品**,不要手動把 AI 原圖放進來。
原圖請放在專案的 `art-src/`(用中文名字,例如 `噗噗.png`),流程見 `docs/art/美術規格.md`。

- `pets/<代號>.png`:寵物主圖,例如 `poring.png`(噗噗)、`imp.png`(小火妖)、`dragon.png`(炎龍)
- `pets/<代號>_attack.png`、`_hurt.png`、`_sleep.png`:可有可無的動作圖
- `npcs/<代號>.png`:NPC,例如 `hatcher.png`、`keeper.png`

有圖就用圖,沒圖就用程式繪圖。
